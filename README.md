# OlisPearlFix

Плагин Paper 1.21.11 / Java 21 для сохранения привязок удочек к ванильным камерам стазиса с жемчугом Эндера.

## Установка

Выполните `gradlew.bat build` на Windows или `sh gradlew build` на Linux. Скопируйте JAR из `build/libs` в `plugins` сервера Paper 1.21.11 и перезапустите сервер. Настройки создаются в папке плагина.

## Использование

Используйте ванильную камеру стазиса и удочку; плагин отслеживает привязки и сохраняет их состояние. `/stasis list` показывает ваши привязки. `/stasis cancel` или `/stasis cancel <UUID>` безопасно отменяет привязку. Право использования: `olispearlfix.use`, административное право: `olispearlfix.admin`. Перед применением на основном сервере проверьте механику на тестовом мире.

Версия 1.1.6. Совместимость с другими версиями Minecraft и Folia не подтверждена.
